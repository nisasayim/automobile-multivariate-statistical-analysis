# Multivariate Statistical Analysis of Automotive Data

## Project Overview

This project applies multivariate statistical methods to Kaggle’s *Car Price Prediction* dataset to investigate relationships among automotive features and assess group differences. Analyses were conducted using R, SPSS, and SAS, focusing on dimensionality reduction, statistical modeling, classification, and data-driven segmentation.

## Analytical Scope and Methodologies

- **Multivariate Analysis of Variance:** One-Way and Two-Way MANOVA to evaluate group differences and factor effects.
- **Dimensionality Reduction:** Principal Component Analysis (PCA) to explore the underlying structure of variables.
- **Factor Analysis:** Identification of latent factors and shared variance among variables.
- **Classification Modeling:** Linear Discriminant Analysis (LDA) and Binary Logistic Regression.
- **Clustering and Segmentation:** Hierarchical Clustering and K-Means to identify groups of automobiles with similar characteristics.

## Technologies

R | SPSS | SAS
